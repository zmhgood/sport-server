# 数据完整性修复与可复现测试

2026-10-13；修复基线 1ecc6d5。只在本机独立 MySQL 使用合成数据运行，没有部署、线上数据修改或小程序审核。

## 已实现的约束

- 移除/退出后再加入恢复同一成员 ID，普通成员角色重新授予；不重复插入唯一键，不恢复旧管理员权限。
- 家庭/目标创建、角色转移、进度与关联流水/日汇总均为事务；家庭锁串行化资格变更，用户锁串行化跨家庭统计与首次创建。故障时整体回滚。
- 失去家庭资格后不能读取当前家庭/目标或提交新进度；个人和家庭历史保留。家庭贡献返回 `is_current_member` 标记离开。
- 目标动作必须属于指定目标；合法绝对组数 0..目标组数。没有进度时提交 0 不创建空行。重复/并发请求只保留一个逻辑每日进度。
- 完成次数按同一人、同一天、同一目标动作全部完成计一次；部分进度计组数，不计完成次数。多家庭同日只计一个个人锻炼日。
- 统计统一读合法关联的最新每日进度，历史重复行仅取最大 ID，不删除源记录；停用/软删除家庭和目标不抹掉历史。流水新增 nullable completion_id 关联，新写入绝对值替换，不累加重试。
- 时长延续现有每组 30 秒的估算，以秒汇总后统一换算分钟，后台文案明确“估算”。业务日期固定 UTC+8。
- 微信错误/无 OpenID/数据库失败不创建空账户；同 OpenID 并发创建恢复同一账户。资料支持性别、身高、体重及可选字段清除，并以服务器回读为准。
- 评论审核仅修改状态，点赞关系和计数原子更新；字数按 Unicode rune。上传检查扩展名、内容签名和体积（不是完整媒体解码）。

## 本地准备与执行

现有本地私有 YAML 仅提供 localhost MySQL 连接。账号需有创建独立库权限；配置不进 Git，也不输出凭据。

```bash
go run ./cmd/testdb create /absolute/path/to/local-private.yaml /tmp/sport-qa-private.yaml
SPORT_INTEGRATION_CONFIG=/tmp/sport-qa-private.yaml go test -count=1 -race -json ./... > /tmp/sport-qa-tests.jsonl
go vet ./...
go build -o /tmp/sport-server-qa ./cmd
go run ./cmd/testdb drop /tmp/sport-qa-private.yaml
rm /tmp/sport-qa-private.yaml
```

prepare 工具只连接 localhost，始终创建唯一 `sport_qa_<timestamp>` 新库；绝不迁移源配置中的业务库。输出文件须不存在，权限 0600，只复制本地数据库凭据，生成临时 JWT 测试密钥，不复制微信/COS等云凭据。失败则清理新库。drop 只允许该生成格式。新增和现有数据库测试均要求本地 `sport_qa_` 库；未提供配置会明确 skip，不能算数据库通过。

## 验证和独立对账

19 个顶层测试函数通过，0 skip；包含 JWT 9 子项、上传 7 子项、原有 3 个 MySQL 测试实际执行。service 集成覆盖重新加入、权限撤销、参数归属/边界、首次并发 10 请求、串行重试、更新归零、创建/转移/流水失败回滚、跨家庭/归档历史、资料持久化、评论并发、旧重复行、超过 1000 条历史、业务周边界和创建 request_id 重试。微信测试拦截网络，10 次并发同 OpenID 只创建一人，不请求真实微信。

固定夹具：同一人同一目标两动作要求 3/2 组，从各 1 组更新到 3/2 组。期望最终 5 组、2 完成动作、1 天、150 秒（2 分钟），重复提交仍一致。独立 SQL 计算后逐一核对个人统计、周统计、历史、日派生表、关联流水和 admin 用户统计；不是只比较调用同一统计函数的两个接口。跨家庭同日、归档和遗留重复行另作夹具。
